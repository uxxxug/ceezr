# وَصْلة (Waslah)

منصة مشاوير وتوصيل عبر بوتات تيليجرام — جدة، مكة، الرياض، الطائف.

> **الحالة الحالية: الأمر الأول منتهٍ (هيكل فقط).**
> لا يوجد منطق أعمال منفّذ خارج `packages/shared`. أي ملف يحمل رأس
> "الحالة: هيكل فقط" **ممنوع** إضافة منطق فيه قبل أمر تفعيل صريح.

## المرجع الحاكم
`docs/MASTER_DIRECTIVE.md` — لا يُخالَف أي بند منه.

## البدء
```bash
bun install
bun run typecheck   # يجب أن ينجح تماماً
bun run test
```

## الهيكل
| المسار | المحتوى |
|---|---|
| `packages/domain/<module>/` | منطق أعمال خالص (هيكل فقط الآن) |
| `packages/application/<module>/` | حالات الاستخدام (هيكل فقط الآن) |
| `packages/infrastructure/<module>/` | محوّلات التكاملات الخارجية (هيكل فقط الآن) |
| `packages/shared/` | **منفّذ فعلياً**: `result`, `kernel`, `config`, `i18n` |
| `apps/gateway/` | خادم Hono + بوتا تيليجرام (هيكل) |
| `apps/workers/` | مهام Cron الخلفية (هيكل) |
| `apps/admin-dashboard/` | لوحة الإدارة (هيكل) |
| `supabase/migrations/` | مخططات القاعدة (تُكتب في الأمر الثاني) |
| `docs/` | ADRs، runbook، api، roadmap |

## القواعد التي تُبطل أي مساهمة عند خرقها
1. لا كود وهمي ولا تعليق "In production this would…".
2. لا قيمة تجارية داخل الكود — كلها في `platform_settings`.
3. `city_id` في كل جدول من أول مخطط.
4. كل عملية حرجة عبر RPC ذرّي في القاعدة.
5. لا ميزة بلا اختبار حقيقي واحد على الأقل.
6. لا دمج PR بلا مرور CI.
