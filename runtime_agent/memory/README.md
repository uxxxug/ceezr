# ذاكرة عامل الوكيل — بيانات تشغيل لا كود

هذا المجلّد يحتفظ به المستودع **فارغاً عن قصد**. ملفّات الذاكرة الفعلية
(`*.json`, `*.jsonl`, `*.tmp`) يكتبها التشغيل نفسه في كل بيئة على حدة،
وهي مُستثناة في `.gitignore` بأمر §4.4 من أمر الإطلاق التجاري:

- نشرُها مع كل نسخة يُحدث تضارباً بين البيئات.
- تراكمها يُضخّم حجم المستودع تدريجياً.
- قد تحمل معلوماتٍ تشغيلية حسّاسة.

المجلّد نفسه لا يُحذَف: الكود يفترض وجود المسار، وحذف المجلّدات ممنوع
بالقاعدة المطلقة في أمر الإطلاق. أي ملف كود (`*.ts`) يبقى متعقَّباً كالمعتاد.
