# إلغاء رحلة بعد قبولها

## ما يراه الطرف الشاكي
قُبل الطلب ثم أُلغي، أو انتظر الطرف الآخر ولم يحضر.

## ما يتحقّق منه فريق الدعم أولاً
حالة الطلب ووقت الإلغاء ومن ألغاه، وسجلّ حضور السائق.

## الردّ المقترح
نأسف لما حدث. راجعنا سجلّ الطلب ووقت الإلغاء، وسنتابع الأمر مع الطرف الآخر.
الإلغاء المتكرّر يؤثّر على تقييم صاحبه في المنصّة.
