## 5. الأحكامُ المسجَّلةُ مسبقًا ونتائجُها

**D مقابلَ A = NOT_CONFIRMED.** المعيارانِ الميكانيكيانِ سقطا: رحلاتُ الالتقاط/وظيفة ‏0.585 → 0.509 = ‏0.87× (المطلوبُ ≤0.75×)، وطابورُ الدرينرِ p95 ‏6.26s → 9.84s = ‏1.57× **أسوأ** لا أفضل. سلامةُ D على main نقيّةٌ (N1–N5 ✓: ‏G1 ‏99.2–99.65% في موجاتِ D الأربع، لا إسنادَ مزدوج، لا وظيفةَ ضائعة) لكنّ النتيجةَ ليست تأكيدًا للآليةِ ولا مكسبًا صافيًا: الحجوزاتُ/وظيفة ‏5.59 → 5.51، وP4 بلا حركةٍ (وسيطُ p95 ‏41.2s → 41.8s)، والانتظارُ لكلِّ حجزٍ 53.5 → 63.9ms وزمنُ المعالجةِ 237 → 288ms.

**X مقابلَ S = REGRESSION.** المعيارُ الميكانيكيُّ الأولُ تحقّق (رحلاتُ الالتقاط 0.169 → 0.081 = ‏0.48×) لكنّ البواباتِ الصلبةَ سقطت: ‏N1 ✗ (G1 فاشلةٌ في موجاتِ X الأربع: ‏90.6–99.0%)، وMD2 ✗، وN4 ✗ (الإلحاقُ الفاشلُ 64–554). بل أسقطت موجتا X4 وS2 أيضًا P1–P3.

**قراءةُ الآلية (وصفيةٌ، لا معيارَ قرار):** على main الدرينرُ شبهُ خاملٍ (مساراتٌ مشغولة p50 ‏0–0.5) فالوظائفُ تصلُ متفرقةً ولا تتكوّنُ دفعاتٌ يلتقطها «حصّةُ البوت» — لذا لم يخفض D الحجوزاتِ إلّا هامشيًا ولم يمسّ P4. آليةُ S هي التي تُشغِلُ الدرينرَ باستمرارٍ (مساراتٌ مشغولة 20/32) فتصيرُ الدفعاتُ ممكنةً — وتحتَها يعملُ الالتقاطُ المسبَقُ (X خفضَ الرحلاتِ إلى النصفِ). لكنّ سقوطَ G1 تحتَ S/X ليس من نمطِ الالتقاط: ‏X أصلحَ الالتقاطَ تمامًا ومع ذلك سقطت G1 في 4/4.
