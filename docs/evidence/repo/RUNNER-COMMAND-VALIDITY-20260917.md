# دليلٌ — `D-24`: صلاحيّةُ نداءِ أوامرِ المشغِّلِ مقيسةٌ لا مفترضةٌ

- **التاريخُ**: 2026-09-17
- **القرارُ الحاكمُ**: [ADR 0144](../../adr/0144-membership-is-not-validity-a-runner-command-must-be-callable.md)
- **يبني على**: [ADR 0143](../../adr/0143-a-guard-that-does-not-fail-the-remote-build-is-not-a-guard.md) ·
  [GUARD-ENFORCEMENT-20260917](GUARD-ENFORCEMENT-20260917.md) §٩

## ١) الواقعةُ

`scripts/check-no-skipped-tests.ts` أُدرِجَ في سلسلةِ `package.json → ci` وهوَ
يستهلكُ وسيطاً، فكانَ نداؤُهُ بلا وسيطٍ يُخفِقُ بخروجِ `1` في كلِّ مرّةٍ —
**ودُمِجَ خضراءَ** في `PR #106`. السببانِ: CI لا تُشغِّلُ السلسلةَ، وحاجزُ
`ADR 0143` يقيسُ العضويّةَ لا الصلاحيّةَ.

## ٢) البرهانُ بالإحياءِ — لا بالدعوى

أُعيدَ العطبُ إلى `package.json` حرفيًّا ثمَّ شُغِّلَ الحاجزُ الجديدُ:

```
✗ 1 مخالفةً في صلاحيّةِ نداءِ أوامرِ المشغِّلِ (D-24):
  • ✗ أمرٌ يستهلكُ وسيطاً ولا يُمرَّرُ لهُ وسيطٌ: «scripts/check-no-skipped-tests.ts»
    يُطبِعُ سطرَ استعمالٍ ثمَّ يخرجُ بغيرِ صفرٍ حينَ لا وسيطَ، والأمرُ
    «bun run scripts/check-no-skipped-tests.ts» لا يُمرِّرُ وسيطاً: نداءٌ يُخفِقُ دائماً.
```

خروج `1` بالعطبِ المزروعِ · خروج `0` بعدَ إعادةِ الملفِّ. **فالحاجزُ يرى العطبَ
الذي وقعَ فعلاً، لا عطباً متصوَّراً.**

## ٣) القياسُ الحاليُّ

| المقيسُ | العددُ |

| أوامرُ السلسلةِ المقروءةُ (بعدَ فكِّ الأسماءِ) | **98** |
| ملفّاتُ `scripts/` على القرصِ | 114 |
| سكربتاتٌ تستهلكُ وسيطاً (عُرفُ سطرِ الاستعمالِ) | **2** (`check-no-skipped-tests.ts` · `measure-db-rtt.ts`) |
| منها في السلسلةِ | **0** |
| إعفاءاتٌ | **0** (السجلُّ فارغٌ بقصدٍ) |
| مخالفاتٌ | **0** |

وحاجزُ تكافؤِ الإنفاذِ بعدَ الإضافةِ: خروج `0` — 91 في المشغِّلِ · 101 في سيرِ
العملِ · 94 حاجزاً على القرصِ · 10 إعفاءاتٍ. والوظيفةُ `verify`: **146 خطوةً**.

## ٤) اختبارٌ سالبٌ لكلِّ قاعدةٍ (`ح-7`)

`tests/unit/check-runner-command-validity.test.ts` — **13 حالةً · 25 `expect()`**:
لكلِّ قاعدةٍ حالةٌ مبذورةٌ تُخفِقُ، وحالةُ المستودعِ الحقيقيّةِ تنجحُ، والكشفُ
غيرُ فارغٍ مفحوصٌ، **والعطبُ التاريخيُّ حالةٌ مسمّاةٌ فيه**. وحالتانِ تحرسانِ
المُحلِّلَ نفسَه: سطرُ استعمالٍ **في تعليقٍ** لا يُقرأُ تنفيذاً، وطبعٌ بلا خروجٍ
بغيرِ صفرٍ لا يُقرأُ استهلاكاً مانعاً.

## ٥) خللٌ في المُحلِّلِ كُشِفَ بالقياسِ وأُصلِحَ

أوّلُ تشغيلٍ أخفقَ بمخالفةٍ **كاذبةٍ**: الأمرُ `bun run --cwd apps/miniapp build`
قُرِئَ فيهِ العلمُ `--cwd` اسمَ سكربتٍ. فأُصلِحَ بتحليلٍ رمزيٍّ للأعلامِ، ويُحَلُّ
سكربتُ الحزمةِ الأخرى في `package.json` الخاصِّ بها بمفتاحٍ مُقيَّدٍ
(`apps/miniapp#build`) — وحالةُ اختبارٍ تحرسُ ذلكَ. **والخللُ يُسجَّلُ ولا يُطمَسُ:
أوّلُ قياسٍ كانَ أحمرَ كذباً، والحمرةُ الكاذبةُ عيبٌ كالخُضرةِ الكاذبةِ.**

## ٦) ما لا يُدَّعى (`ح-5`)

- **لا يُدَّعى أنَّ أمراً يَنجَحُ**؛ يُدَّعى أنَّه **يُنادى كما كُتِبَ**.
- **لا يُدَّعى** أنَّ CI صارَت تُشغِّلُ `bun run ci` — لم تفعلْ، والسببُ مكتوبٌ في
  `ADR 0144 §٤` (تكرارُ مصدرِ الحقيقةِ).
- **لا يُدَّعى** أنَّ الثمانيةَ والثمانينَ حاجزاً «مضمونةٌ»: شُغِّلَت واحداً واحداً
  **مرّةً واحدةً بيدِ منفِّذٍ** — قياسٌ نقطيٌّ لا بوّابةٌ دائمةٌ.
- **لا يُدَّعى** أنَّ العُرفَ يُصيبُ كلَّ استهلاكٍ: سكربتٌ يشترطُ وسيطاً ولا
  يُطبِعُ استعمالاً لا يراهُ الحاجزُ — نقصٌ مُعلَنٌ في `D-24`.
- **ولذا يبقى `D-24` جزئيًّا (`[~]`) لا مُغلَقاً.**
