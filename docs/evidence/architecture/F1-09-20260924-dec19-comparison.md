## ١. تصحيحُ العباراتِ الثلاثِ

المصدرانِ الحرفيّانِ:
[`NetworkManager.ts` في Chromium DevTools](https://chromium.googlesource.com/devtools/devtools-frontend/+/refs/heads/main/front_end/core/sdk/NetworkManager.ts)
و[تعريفُ `Network.emulateNetworkConditions` في بروتوكولِ DevTools](https://raw.githubusercontent.com/ChromeDevTools/devtools-protocol/master/pdl/domains/Network.pdl).

```ts
const slow3GTargetLatency = 400;
export const Slow3GConditions = {
  download: 500 * 1000 / 8 * .8,   // 50,000 بايت/ث
  upload:   500 * 1000 / 8 * .8,   // 50,000 بايت/ث
  // 400ms RTT
  latency: slow3GTargetLatency * 5, // 2,000 ms
};
```

و`latency` في البروتوكولِ حرفاً: «Minimum latency from request sent to response headers received (ms)».
واسمُ هذا الملفِّ في واجهةِ DevTools اليومَ **«3G»** (`UIStrings.slowG = '3G'`) لا «Slow 3G».

### ٢-ج. ملاحظاتُ صدقِ القياسِ

1. **بوّابةُ `FCP` الحاليّةُ تقيسُ شاشةً لا يراها مستخدمٌ يفتحُ من تيليجرام**: شاشةُ «افتح وَصْلة
   من تيليجرام» تظهرُ بلا `initData`. والمستخدمُ الحقيقيُّ يصلُ بـ`initData` فأوّلُ ما يُرسَمُ له
   سطحُ الراكبِ (FCP = TTI + ≈ 25 ms في كلِّ تشغيلٍ — لا شيءَ يُرسَمُ قبلَه).
2. **علامةُ التفاعلِ تسبقُ LCP بنحوِ 600 ms على «Slow 4G»** (و≈ 2 s على «3G»): LCP يقعُ بعدَ
   اكتمالِ `/v1/consents`. فالعلامةُ تعني «بلوغُ السطحِ» لا «اكتمالُ محتواه».
3. **عيبٌ كامنٌ في `scripts/measure-tti.ts` على `main`**: مراقبُ LCP يُرشِّحُ `e.name === "largest-contentful-paint"`،
   ومُدخَلاتُ LCP اسمُها فارغٌ، فـ`lcp` دائماً `null`. **بلا أثرٍ على البوّابةِ اليومَ** (LCP لا
   يُقرأُ في حكمِ الصفِّ ٥)، وأُصلِحَ في فرعِ القياسِ وحدَه ليُقاسَ LCP أعلاه. ولا يُصلَحُ في `main`
   هنا (أمرُ المالكِ: لا شيفرةَ).
4. الأرقامُ **حدٌّ أدنى**: سكربتُ `telegram.org` محجوبٌ، والمُنفِّذُ ليسَ جوّالاً، والضغطُ `gzip`.

## ٣. ما الذي يتغيّرُ إنِ اعتُمِدَ «Slow 4G»

**الاسمُ ونموذجُ الشبكةِ معاً — وهوَ تغييرٌ في معيارِ القبولِ لا تسميةٌ**:

| البُعدُ | «3G» → «Slow 4G» |
|---|---|
| التأخيرُ لكلِّ طلبٍ | 2000 → 562.5 ms (أقلُّ بـ72%) |
| التنزيلُ | 50,000 → 180,000 B/s (×3.6) |
| الرفعُ | 50,000 → 84,375 B/s (×1.69) |
| المعالجُ | ×4 → ×4 (بلا تغييرٍ) |
| نصُّ 9.9 | «على 3G بطيء» يصيرُ شبكةً ليست 3G — تعديلٌ لنصٍّ حاكمٍ (`ح-1`) بقرارِ المالكِ |

لا بندَ قُلِبَ، ولا معيارَ عُدِّلَ، ولا حدَّ خُفِّفَ، ولا سقفَ خرقٍ تغيَّرَ. و`F1-09` يبقى `[~]`
و`DEC-19` `[!]`. وهذهِ الأرقامُ مدخلٌ لقرارِ المالكِ لا توصيةٌ بملفٍّ بعينِه.
