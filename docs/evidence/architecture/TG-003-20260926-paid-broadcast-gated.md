# دليلُ TG-003 — البثُّ المدفوعُ محجوزٌ بقرارٍ لا مُفعَّلٌ بلا قرارٍ

**التاريخ**: 2026-09-26
**البند**: `TG-003` (الشقُّ المملوكُ للمستودَعِ)
**القرار**: ADR 0199
**الحالة**: الشقُّ المملوكُ للمستودَعِ منفَّذٌ — `TG-003` يبقى `[ ]` (التمكينُ الفعليُّ بيدِ المالكِ)

## ما قِيسَ

### الأرقامُ النافذةُ (مُتحقَّقٌ منها من المصادرِ الرسميّةِ يومَ 2026-09-26)

| البندُ | القيمةُ | المصدرُ |
|---|---|---|
| الحدُّ المجاني | ٣٠ رسالةً/ثانيةً | [Bot API FAQ](https://core.telegram.org/bots/faq) |
| سقفُ البثِّ المدفوع | ١٠٠٠ رسالةٍ/ثانيةً | [Bot API](https://core.telegram.org/bots/api) |
| السعرُ | ٠٫١ نجمةٍ/رسالةً فوقَ الحدِّ المجاني | [Bot API](https://core.telegram.org/bots/api) |
| رصيدُ النجومِ الأدنى للتمكين | ١٠٠٬٠٠٠ نجمة | [Bot API FAQ](https://core.telegram.org/bots/faq) |
| المستخدمون النشطون شهريًّا الأدنى | ١٠٠٬٠٠٠ مستخدم | [Bot API FAQ](https://core.telegram.org/bots/faq) |

### التقديرُ الاقتصاديُّ

- ١٠٠٬٠٠٠ نجمة ≈ ١٬٠٠٠–٢٬٥٠٠ دولارًا أمريكيًّا (بحسبِ سعرِ TON) رصيدٌ مُجمَّدٌ لا يُستهلَكُ.
- ٠٫١ نجمة/رسالة ≈ ٠٫٠٠١–٠٫٠٠٢٥ دولارًا/رسالة.
- تفعيلُ البثِّ المدفوعِ يتطلّبُ ١٠٠٬٠٠٠ مستخدمٍ نشطٍ شهريًّا — وكلاهُما خارجُ نطاقِ الإطلاقِ الأوّلِ.

### الحاجزُ

`scripts/check-paid-broadcast-guard.ts` بثلاثِ قواعدَ:
- `no-allow-paid-broadcast`: لا وجودَ للنصِّ في الشيفرةِ.
- `adr-required`: إن وُجدَ، يُشتَرَطُ ADR 0199 موجودًا.
- `owner-decision-required`: إن وُجدَ، يُشتَرَطُ تعليقٌ على TG-003 يقولُ إنَّ DEC-04 حُسِمَ بالفتحِ.

## ما لا يُدَّعى

- لا يُدَّعى أنَّ التكلفةَ الكلّيّةَ محسوبةٌ — تتوقَّفُ على حملٍ لم يُقَسْ بعدُ (`F10`).
- لا يُدَّعى أنَّ الأرقامَ لن تتغيَّرَ — يجبُ إعادةُ التحقُّقِ منها لحظةَ القرارِ الفعليِّ.
- لا يُدَّعى أنَّ البثَّ المدفوعَ مُفعَّلٌ — هوَ محجوزٌ بقرارِ مالكٍ (`DEC-04` `[!]`).
- `TG-003` يبقى `[ ]` لأنَّ التمكينَ الفعليَّ (تمريرُ `allow_paid_broadcast: true` في
  الإنتاجِ) بيدِ المالكِ ولا يُنفَّذُ في المستودَعِ.
