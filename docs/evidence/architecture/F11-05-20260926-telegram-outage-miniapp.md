# F11-05 (الشقُّ المملوكُ للمستودَعِ) — عطلُ Bot API لتيليجرام لا يُسقِطُ مساراتِ Mini App

**التاريخ**: 2026-09-26 · **الفرعُ**: `feat/f11-05-telegram-outage-miniapp` من `main`@`167e8f08` · **القرارُ**: `ADR 0198`

## المقيسُ قبلَ التغييرِ

- لا اختبارَ يُطفِئُ Bot API لتيليجرام تحتَ جلسةِ Mini App نشطةٍ ويقرأُ المساراتِ الحيّةَ.
- `createTelegramApi` يقبلُ `fetchImpl` للحقنِ لكنَّه لم يُختبَرْ بعطلِ اتصالٍ فعليٍّ.
- القاطعُ (`DEPENDENCY_BUDGETS.telegram`: `failureThreshold` ١٠) لم يُقَسْ في مسارِ Mini App.

## الفرضيّةُ المُختبَرةُ

«جلسةُ Waslah الداخليّةُ القائمةُ تستمرُّ، ومساراتُ Mini App بعدَ المصادقةِ لا تنتظرُ Bot API،
وفشلُ الإشعارِ معزولٌ ومرئيٌّ.» لا يحلُّ `TG-004`/`ARCH-014` — تلك تتطلّبُ مصادقةً بديلةً ونشراً حيًّا.

## القياسُ المحلّيُّ

| المسارُ | الخطُّ الأساسُ | أثناءَ العطلِ | ملاحظةٌ |
|---|---|---|---|
| `GET /v1/me` | 200 | 200 | لا يعتمدُ على Bot API |
| `GET /v1/rides/:id` | 200 | 200 | يقرأُ من PostgreSQL |
| `GET /v1/rides` | 200 | 200 | يقرأُ من PostgreSQL |

| سببُ الفشلِ | موثَّقٌ | `Connection refused` |
| رفضُ القاطعِ | نعمٌ | `TelegramGuardRejection` |

## ما لا يُحلُّ ههنا

- **`TG-004`/`ARCH-014`**: مصادقةٌ بديلةٌ ونشرٌ حيٌّ (`DEC-07`). الشقُّ ههنا عزلُ العطلِ لا حلُّ الاعتماديّةِ.
- **الإنتاجيّةُ**: رحلةٌ واحدةٌ تحتَ عطلٍ محقونٍ، لا حملٌ ولا نشرٌ حيٌّ (`ح-4`/`ح-5`).
- **`outbox` كاملًا**: المُرسِلُ يُستدعى مباشرةً على السِلكِ، لا عبرَ صفوفِ `notification_outbox`.

## إصلاحٌ جانبيٌّ: غموضُ تحميلِ `rider_ride_history`

أثناءَ اختبارِ التكاملِ اكتُشِفَ أنَّ نداءَ `rider_ride_history` عبرَ `sql.unsafe` بلا
تصريحِ أنواعٍ يُسقِطُه PostgreSQL لغموضِ التحميلِ (دالّتانِ بنفسِ الاسمِ ومعامِلاتُ مختلفةٌ).
أُصلِحَ بإضافةِ تصريحِ الأنواعِ (`$1::bigint`, `$2::text`, ...) في `ride-history-store.ts`.
هذا إصلاحُ عيبٍ إنتاجيٍّ حقيقيٍّ لا تكييفُ اختبارٍ.
