# دليل قرار DEC-16 — الاكتفاءُ بالتجميعاتِ المادِّيّةِ (2026-09-20)

| الحقل | القيمة |
| --- | --- |
| البند | DEC-16 · F7-08 · F7-05 · CAP-011 |
| التاريخ | 2026-09-20 |
| المنفِّذ | وكيل Perplexity Computer |
| القرار | الخيار (ب) — الاكتفاءُ بالتجميعاتِ المادِّيّةِ. لا نسخةَ قارئةً |

---

## ١) السياق

`DEC-16` كانَ مفتوحاً منذ 2026-09-16 ينتظرُ قراراً يفصلُ بين مسارَين:

- **(أ) تمويلُ نسخةٍ قارئةٍ**: نسخةٌ قارئةٌ منفصلةٌ بكلفةٍ شهريّةٍ وحدِّ إقامةٍ يشتبِكُ بـ`DEC-01` (توطينُ البيانات).
- **(ب) الاكتفاءُ بالتجميعِ المادِّيِّ**: التجميعُ المادِّيُّ الموجودُ (`admin_metric_snapshots` + `refresh_admin_metric_snapshots`) هو الحلُّ النهائيُّ.

اختارَ المالكُ الخيارَ (ب).

## ٣) جولاتُ `main` الخضراءُ (ح-4)

ثلاثُ جولاتٍ متتاليةٍ على `main` قبلَ هذا القرارِ — الوظائفُ الأربعُ (`verify` · PostgreSQL · Redis · chaos) `success` في كلِّها:

1. `35115060956` @ `09e05ef`
2. `35116319583` @ `1b79426`
3. `35127423244` @ `e2ebd66`

## ٤) ما لا يُدَّعى (ح-5)

- لا `مَقيس` ولا `مُثبَت` — لا قياسَ حملٍ إنتاجيٍّ
- الكتابةُ تظلُّ تقرأُ الجداولَ الحارّةَ كلَّ ٦٠ ثانيةً (حملٌ ثابتٌ مقبولٌ بقرارِ المالكِ)
- لا يُدَّعى أنَّ التجميعَ المادِّيَّ يُغني عن النسخةِ في كلِّ حجمٍ — القرارُ للمُشهدِ الحاليِّ
