## ما تم

- إنشاء `apps/miniapp` كحزمة workspace مستقلة.
- بناء Vite + React 19 + TypeScript، إخراج أصول ثابتة في `dist/`.
- تقسيم أولي للحزم وفق ROADMAP §9.4: `shell` · `identity` · `tg` · `api`.
- RTL عربي افتراضي وربط CSS variables بـ ThemeParams.
- حامل جلسة Waslah محلي **بدون** إنشاء كيانات دومين.
- حارس `apiFetch` يرفض أي نداء منتج بلا جلسة (فحص ADR 0035 رقم 2).
- تغليف `tg/` لكل استدعاءات WebApp.

## الاختبار

- `apps/miniapp/src/identity/session.test.ts` — حامل الجلسة.
- `apps/miniapp/src/api/client.test.ts` — حارس الجلسة قبل الشبكة.

تشغيل متوقع بعد `bun install` داخل الحزمة:

```text
bun test src
```

## الحكم

`F1-01` منجز على مستوى الهيكل والبناء الثابت والعقد المانع لحالة العمل. البوابة الكاملة لـ F1 (مستخدم حقيقي من تيليجرام بجلسة موثّقة) تتطلب F1-03..F1-10 ولن تُدّعى هنا.

## حدود معروفة

- اعتماديات React/Vite تُثبَّت عند أول `bun install` في الحزمة (غير موجودة في `bun.lock` الجذري بعد).
- سكربت `telegram-web-app.js` من `telegram.org` مسموح كاستثناء رسمي لـ Mini Apps؛ لا أصول تنفيذية أخرى.
- `biome.json` الجذري يفحص `**/*.ts` فقط؛ ملفات `.tsx` خارج نطاق الـ lint الحالي (يُعالَج في بند لاحق دون كسر `ح-1`).
