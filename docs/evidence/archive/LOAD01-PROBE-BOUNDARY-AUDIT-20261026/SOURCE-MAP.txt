# 4. إعادةُ الإنتاجِ (بلا توليدِ bytecode)

الأداةُ تستوردُ المحلّلَ في الاختبارِ الذاتيّ، وأيُّ استيرادٍ يولّد `__pycache__` داخلَ
دليلِ الأدلةِ فيُفشلَ حاجزَ بياناتِ الأدلةِ (ملفٌّ غيرُ مُدرَج). **الحلُّ المسجّلُ في
البروتوكولِ:** شغّل المحلّلَ والاختبارَ الذاتيَّ بـ`PYTHONDONTWRITEBYTECODE=1` فلا
يولَّد `__pycache__` أصلًا — وهذا موثّقٌ هنا وفي دليلِ الدورةِ، والتحققُ أدناه
يُنفَّذ بهذهِ الصيغةِ (بلا تنظيفٍ يدويٍّ):

```sh
cd docs/evidence/capacity/LOAD01-PROBE-BOUNDARY-AUDIT-20261026
PYTHONDONTWRITEBYTECODE=1 python3 analyze-probe-boundary-selftest.py   # PASS
PYTHONDONTWRITEBYTECODE=1 python3 analyze-probe-boundary.py \
  ../../archive/LOAD01-PROBE-BOUNDARY-AUDIT-20261026/samples \
  ../../archive/LOAD01-C2-HTTP-WAIT-PROBE-20261026/raw-summaries \

# ثم حاجزُ بياناتِ الأدلةِ مباشرةً (لا __pycache__ بينهما)؛
# هذا الدليلُ على عمقِ أربعةٍ من جذرِ المستودعِ فيجبُ الصعودُ أربعَ مراتٍ:
```
