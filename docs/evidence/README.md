# مجلد الأدلة

هذا المجلد هو الذاكرة الوحيدة المقبولة لإثبات أي إنجاز في `docs/ROADMAP-MASTER.md`.

> **القاعدة:** وضع `[x]` أمام بند في الخارطة بلا ملف دليل هنا وبلا سطر في سجل التنفيذ (القسم 25) **مخالفة صريحة** للمحرَّم `ح-4`.

## التسمية

```text
docs/evidence/<التصنيف>/<معرّف البند>-<YYYYMMDD>.<md|txt|json>
```

أمثلة: `correctness/BUG-001-20260901.md` · `capacity/F10-02-20261115.json` · `compliance/F12-03-20260930.md`

إذا أُعيد التنفيذ لاحقاً، **لا يُستبدل الملف القديم**؛ يُضاف ملف جديد بتاريخ جديد، ويبقى القديم للمقارنة والتاريخ.

## التصنيفات

| المجلد | ما يوضع فيه |
|---|---|
| `architecture/` | قرارات وهياكل معمارية منفَّذة، بنود F0 و F1، إثبات فصل العمليات |
| `correctness/` | إغلاق عيوب الصحّة والسباقات (`BUG-*`) — لكل عيب: اختبار يُعيد إنتاجه قبل الإصلاح، ونجاحه بعده |
| `distributed/` | إثبات نزع الحالة المحلية (`SCL-*`): عدّة مثيلات تعمل معاً، وقتل مثيل بلا فقدان خطوة المستخدم |
| `security/` | الهوية، التفويض على مستوى الكائن، الأسرار، منع الإساءة، التدقيق |
| `capacity/` | نتائج القياس (`CAP-*`، F9، F10، بوابات السعة A–F). **إلزامي:** بصمة الإعدادات، الـtopology، نسخة الحِمل، وتكرار النتيجة |
| `chaos/` | سيناريوهات الفشل المُتعمَّد أثناء الحمل (F11) |
| `recovery/` | تدريبات الاستعادة، النسخ الاحتياطي، RTO/RPO المقيسة فعلياً، اختبارات الـrollback |
| `release/` | الـcanary والموجات والنشر التدريجي وسجلات القرار (F13) |
| `compliance/` | الامتثال التنظيمي (F12): هيئة النقل، PDPL، الدفع، الفاتورة الإلكترونية |

## المحتوى الإلزامي لكل ملف دليل

1. **الـcommit** الذي جرى عليه العمل.
2. **بصمة الإعدادات** (متغيّرات البيئة المؤثّرة بلا أسرار، أحجام التجميع، الحدود).
3. **الـtopology** (عدد المثيلات، القاعدة، Redis، الطابور، المناطق).
4. **نسخة الحِمل** إن وُجدت (`capacity-profile-v1` أو أحدث).
5. **النتيجة** بالأرقام لا بالوصف.
6. **الأخطاء** التي ظهرت، حتى المُتجاوَز عنها.
7. **الحدود المعروفة** — ما لم يُختبَر بعد.
8. **الحُكم النهائي**: نجاح أو فشل، ودرجة الدليل من سلّم القسم 1.4.

بلا الحُكم النهائي وبلا الحدود المعروفة، الملف **لا يُعتبر دليلاً**.

## ملاحظة

الملفات المسطّحة في جذر هذا المجلد سابقة لهذه البنية، وتُحفظ كما هي مرجعاً تاريخياً. الأدلة الجديدة تُوضع في التصنيفات أعلاه فقط.
