## A — ما تتفق عليه الملفات الثلاثة

1. **الهوية:** Premium Utility — حديثة، فاخرة، حية، هادئة، إنسانية، واضحة وسريعة. لا Uber/Careem clone.
2. **النظام البصري:** طبقتان — محايدات تيليجرام (Layer 1) + هوية ثابتة (Layer 2). الألوان: brand, amber, ok, bad, mute. كل حالة لها نص وأيقونة، لا لون وحده.
3. **الطباعة:** خطوط النظام فقط. تدرّج: display 1.75rem/800 → caption 0.75rem/500. عربية بلا letter-spacing ولا text-transform. أرقام تينية. logical properties فقط.
4. **المكوّنات:** مكتبة `ui-*` موحّدة (ui-btn, ui-fld, ui-tile, ui-chip, ui-card, ui-row, ui-kv, ui-truth, ui-rail, ui-timer, ui-stp, ui-sht, ui-dg, إلخ).
5. **التنقل:** تبويب جذري (4 عناصر للراكب، 4 للسائق) + stack للتدفقات. لا tab bar داخل التدفقات.
6. **الحالات:** تحميل/فارغ/خطأ/مرفوض/غير متاح/متقادم/غير مقيس — كل حالة كاملة بصريًا.
7. **الصدق:** لا خريطة وهمية، لا ETA وهمي، لا سعر وهمي، لا دفع وهمي، لا محادثة غير مبنية، لا timer وهمي.
8. **CSS مسطّح:** لا @layer، لا تداخل، لا !important. لا مكتبات جديدة (لا Framer Motion، لا مكتبة أيقونات).
9. **الأداء:** shell+identity ≤ 180KB gzip. CSS مدمج ≤ 40KB gzip. ≤ 6 طلبات أول رسم.
10. **الأمن:** لا تُضعف CSP/CSRF/authorization. الواجهة تعرض ولا تقرر.
11. **RTL/LTR:** logical properties فقط. ar/en/ur بتماثل المفاتيح.
12. **العقود:** ملفات `*contract.ts` و`*api.ts` و`*view.ts` تبقى — يتغيّر العرض فقط.
13. **التصنيف:** [A] قائم، [B] خادم جاهز والواجهة غائبة، [C] يحتاج قرار مالك، [D] ممنوع.
14. **CI:** كل البوابات خضراء قبل كل PR.
15. **القاعدة الحاكمة:** الكود + الحالة + التوثيق تتحرك معًا.

## D — القرارات التي حُسمت

1. **v2.0 هو المرجع الحاكم** عند تعارض تفاصيل التنفيذ بين v1.0 و v2.0.
2. **lTryq.txt يحكم الاتجاه التصميمي العام** ما لم يخالف الواقع أو v2.0.
3. **الأفكار التسع (§13 في v2.0) معتمدة** وليست اختيارية — يجب تنفيذها أو توثيق سبب تأجيلها.
4. **الخارطة القديمة (ROADMAP.md) تصبح تاريخية** بعد التحقق منها — المرحلة النشطة الجديدة هي UI/UX REFOUNDATION.
5. **لا تغيير في العقود** — `*contract.ts` و`*api.ts` و`*view.ts` تبقى كما هي.
6. **CSS مسطّح بلا مكتبات جديدة** — هذه قاعدة غير قابلة للتفاوض.
7. **Branch protection غير مفعّل** — يتطلب قرار مالك (GitHub settings).
8. **check-state-sync بوابة جديدة** — تُضاف لمنع تغيير تنفيذي بلا تحديث الحالة.
