# ADR 0003 — `city_id` في كل جدول من أول مخطط

**الحالة:** مقبول
**التاريخ:** الأمر الأول

## السياق
مدن الإطلاق الخمس (جدة، مكة، الرياض، الطائف، والمدينة المنورة) تُفعَّل معاً منذ أول مرحلة فعلية؛ لا تؤجَّل المدينة المنورة (`MED`)، والتوسّع لمدن أخرى قرار لاحق.

## القرار
كل جدول — بلا استثناء، حتى ما يبدو محلياً — يحمل `city_id NOT NULL REFERENCES cities(id)`، وتُبنى سياسات RLS على أساسه.

## النتائج
لا حاجة لهجرة مؤلمة عند إضافة مدينة؛ إضافة مدينة = صف في `cities` + ثلاثة معرّفات قروبات.
