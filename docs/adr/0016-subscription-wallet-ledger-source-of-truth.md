# ADR 0016: دفتر حركات محفظة الاشتراك هو مصدر الرصيد

- الحالة: مقبول، 2026-08-13
- القرار: لا يوجد عمود رصيد قابل للتحديث في `subscription_wallets`. يُحسب الرصيد قانونياً من مجموع `subscription_wallet_entries` (الدائن ناقص المدين) داخل `subscription_wallet_balance`.
- السبب: التحديثات المتزامنة للرصيد المخزّن قد تفقد حركة، بينما الإدخالات غير القابلة للتعديل مع مفاتيح الإيدمبوتنسي ومصادر الدفعة الفريدة تجعل كل ائتمان أو خصم قابلاً للمراجعة. عمليات الكتابة كلها RPCs ذرية وتقفل الصفوف المناسبة.
- النتيجة: القراءة تجمع الدفتر؛ يفيد الفهرس على `wallet_id, created_at`. هذه محفظة ائتمان اشتراك فقط ولا تحمل أجرة رحلة أو عمولة أو تسوية مشوار.
