# 0228 — رابطُ قراءةٍ موقَّعٌ لوثائقِ السائقِ في الميني-أب (DEC-31)

| الحقلُ | القيمةُ |
|---|---|
| الحالةُ | مقبولٌ |
| التاريخُ | 2026-10-01 |
| السياقُ | `DEC-31` — تنشيطُ دَينٍ مُعلَنٍ |
| المرتبطُ | `documents-contract.ts` · `driver-documents.ts` · `signed-read.ts` |

## القرارُ

إضافةُ مسارِ `GET /v1/driver/documents/:docType/read-url` — يُوقِّعُ رابطَ قراءةٍ
للوثيقةِ المرفوعةِ عبرَ `ReadUrlSigner` نفسِهِ الذي يخدمُ أصولَ المركبةِ (F12-06) ولوحةَ
الإدارةِ (DEC-25).

## الدافعُ

`documents-contract.ts` كانَ يُعلِنُ: «لا رابطَ قراءةٍ للوثيقةِ المرفوعةِ: دَينٌ
مُعلَنٌ — اللوحُ يقولُ الحالةَ والتاريخَ لا الصورةَ». فالسائقُ يرفعُ وثيقةً ولا يستطيعُ
رؤيتَها.

## التصميمُ

- `readObjectPath` method جديدةٌ في `DriverDocumentStore` — تُعيدُ مسارَ الكائنِ لنوعِ وثيقةٍ.
- `readSigner?` مُحقَنٌ في `DriverDocumentDeps` — اختياريٌّ: غيابُهُ `503`.
- `readDriverDocumentUrl` دالّةُ تطبيقٍ — تفتحُ الجلسةَ، تتحقَّقُ من النوعِ، تقرأُ المسارَ، تُوقِّعُ الرابطَ.
- `OBJECT_NOT_SUBMITTED` رمزُ عطلٍ جديد — للوثيقةِ التي لم تُرفَعْ.
- `readDriverDocumentUrl` في `documents-api.ts` — نداءُ `apiFetch` بسيطٌ.

## الأمانُ

- المسارُ لا يُعيدُ `object_path` للعميلِ — يُوقِّعُ رابطَ قراءةٍ فحسب.
- الجلسةُ مطلوبةٌ — لا وصولٌ بلا رمزٍ موقَّعٍ.
- الرابطُ ينتهي بعدَ ٥ دقائقَ (`ttlSeconds: 300`).

## القياسُ

٤ اختباراتِ وحدةٍ: رابطٌ موقَّعٌ، رفضٌ بـ `OBJECT_NOT_SUBMITTED`، رفضٌ بـ `UPLOAD_NOT_AVAILABLE`،
رفضٌ بـ `DOC_TYPE_UNKNOWN`.

## العواقبُ

- السائقُ يستطيعُ رؤيةَ وثيقتِهِ المرفوعةِ عبرَ رابطٍ موقَّعٍ ينتهي بعدَ ٥ دقائقَ.
- المسارُ اختياريٌّ — غيابُ المُوقِّعِ لا يُعطِّلُ اللوحَ.
