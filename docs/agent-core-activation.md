# تفعيل طبقة الذكاء الاصطناعي على الإنتاج وبدء القياس

- **الحالة:** تعليمات تشغيل — موجّهة لصاحب المشروع
- **آخر تحديث:** 2026-08-08

> **⚠️ ثلاث خطوات من هذا المستند لا يستطيع أحد غيرك تنفيذها**: ضبط متغيّرات Render،
> وتطبيق الهجرة على Supabase، وتحديد من في قروب الدعم. الكود جاهز ومُختبَر، لكنه
> **لا يفعل شيئاً حتى تُنفَّذ هذه الثلاث**.

## أين نحن الآن بالضبط

- الطبقة **معطَّلة** على الإنتاج: `AGENT_CORE_ENABLED` غير مضبوط.
- قاعدة Supabase (`mlwyxecncuyebqwcjfmc`) **فارغة تماماً**: لا جداول ولا هجرات
  مطبَّقة. لا يوجد نظام منشور، ولا تذكرة دعم حقيقية واحدة في الوجود.
- حلقة القياس **مغلقة في الكود ومُبرهَنة باختبارات** على قاعدة حقيقية محلياً.

فالمتبقّي ليس برمجة، بل **نشرٌ وتشغيل وانتظار عيّنة**.

## الخطوة 1 — تطبيق الهجرات على Supabase

الهجرات في `supabase/migrations/` بالترتيب الزمني لأسمائها، وآخرها
`20260808180000_phase_3_agent_measurement.sql` (جدولا القياس).

```bash
supabase link --project-ref mlwyxecncuyebqwcjfmc
supabase db push
```

للتحقّق بعدها — يجب أن يعود 20 جدولاً، ومنها `agent_decisions` و`agent_outcomes`:

```sql
select table_name from information_schema.tables
 where table_schema = 'public' order by 1;
```

## الخطوة 2 — متغيّرات البيئة على Render

| المتغيّر                     | القيمة                | ملاحظة                                     |
| --------------------------- | --------------------- | ------------------------------------------ |
| `AGENT_CORE_ENABLED`        | `true`                | **لا شيء غير `true` حرفياً يُفعّلها**        |
| `AGENT_CORE_PERSISTENCE`    | `file`                | الذاكرتان القصيرة والمتوسطة                 |
| `AGENT_CORE_RUNTIME_ROOT`   | `/opt/render/project/src/runtime_agent` | يُمحى عند كل نشر — مقبول |
| `AGENT_CORE_CONFIDENCE_THRESHOLD` | `0.55`          | دون هذا لا يُنشر اقتراح                     |

> **⚠️ لا تضبط أي مفتاح API لنموذج لغوي.** النموذج المربوط `nullModel.ts` عمداً،
> والوكيل يعمل بقواعد صريحة لا بنموذج. ربط مفتاح الآن قرارٌ آخر لم يُتّخذ.

بعد الحفظ يُعيد Render النشر تلقائياً. تأكّد من ظهور
`agent_core.knowledge_loaded` في السجلّ.

## الخطوة 3 — أخبر فريق الدعم بجملتين

اكتبها لهم كما هي، فسوء الفهم هنا يُفسد العيّنة كلّها:

> ستظهر تحت بعض تذاكر الدعم **رسالة اقتراح آلي** فيها زرّان: 👍 و 👎.
>
> 1. **الاقتراح للقراءة فقط.** لم يُنفَّذ أي إجراء، ولن يُنفَّذ. القرار لكم كما كان.
> 2. **الزرّان للتقييم لا للتنفيذ.** نقرُهما لا يفعّل اشتراكاً ولا يحسم تذكرة ولا
>    يستلمها — يسجّل رأيكم فقط. عاملوا التذكرة كما تعاملونها دائماً.

**لا تقل لهم «جرّبوا الاقتراح».** أهم رقم عندنا هو **كم مرّة كان الاقتراح صواباً
لو لم يره أحد**، ولو غيّر وجودُه سلوكَهم قِسنا أثر الاقتراح على الموظّف لا صوابه.

## الخطوة 4 — الانتظار، ثم القراءة

```bash
DATABASE_URL=<رابط Supabase> bun run scripts/agent-effectiveness.ts
```

> **⚠️ التقرير يمتنع عن طباعة أي نسبة قبل 30 حكماً**، وهذا مقصود. نسبةٌ من عيّنة
> صغيرة تُقرأ كأنها حكم وهي ضجيج. اقرأه أسبوعياً وانتظر بلوغ الحدّ.

وحين تعلو حصّة الاستنتاج الآلي 70% سينبّهك التقرير: النسبة حينها تقيس اتّساق
الوكيل مع قواعدنا أكثر ممّا تقيس صوابه، لأن أغلب الأحكام لم ينقرها إنسان.

## الخطوة 5 — التوسيم اليدوي الدوري

مرّة كل أسبوع، صدّر ما لم يحكم عليه إنسان:

```bash
DATABASE_URL=<...> bun run scripts/agent-effectiveness.ts --export-unlabeled 20
```

اقرأ نصّ التذكرة والتصنيف المقترح، ثم:

```bash
DATABASE_URL=<...> bun run scripts/agent-effectiveness.ts \
  --label <traceId> --verdict accepted --note "مراجعة 2026-08-15"
```

توسيمك يعلو الاستنتاج الآلي ويخضع لنقرة الموظّف — والقاعدة تفرض ذلك، لا الاتفاق.

## ما يجب أن **لا** يحدث بعد التفعيل

راقب هذه، وظهور أيّها يعني أن شيئاً جوهرياً انكسر:

```sql
-- ⚠️ يجب أن يعود صفراً دائماً. أيّ صفّ هنا يعني أن سقف SUGGEST خُرق.
select count(*) from agent_decisions where allowed_tool_level <> 'SUGGEST';

-- ⚠️ تذكرة حُسمت في اللحظة نفسها التي نُشر فيها اقتراحها = نقرة على زرّ خاطئ.
select count(*) from agent_decisions d join support_tickets t on t.id = d.ticket_id
 where t.resolved_at is not null and t.resolved_at - d.created_at < interval '2 seconds';
```

## التراجع

اضبط `AGENT_CORE_ENABLED=false` (أو احذفه) وأعد النشر. يعود مسار الدعم إلى ما كان
عليه حرفاً بحرف: لا اقتراح، ولا أزرار تقييم، ولا كتابة في جدولي القياس. والبيانات
المتراكمة تبقى كما هي، فالتراجع لا يُتلف قياساً مضى.

اختبار العزل في `tests/integration/agent-core-support-advice.test.ts` يبرهن هذا
المسار بالتعطيل لا بالوعد.
