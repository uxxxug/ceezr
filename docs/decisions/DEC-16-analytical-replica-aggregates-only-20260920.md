# DEC-16 — قرارُ المالكِ: الاكتفاءُ بالتجميعاتِ المادِّيّةِ دون نسخةٍ قارئةٍ

| الحقل | القيمة |

| الحالة | **مُغلَق — قرارُ مالكٍ صريحٌ: الاكتفاءُ بالتجميعاتِ المادِّيّةِ** |

## ١) نصُّ القرارِ

> الخيار (ب) — الاكتفاءُ بالتجميعاتِ المادِّيّةِ. لا نسخةَ قارئةً. التجميعُ المادِّيُّ الموجودُ (`admin_metric_snapshots` + `refresh_admin_metric_snapshots`) هو الحلُّ النهائيُّ. الساقُ الثالثةُ من `F7-08` مُسقَطةٌ بقرارِ المالكِ.

## ٢) ما يترتّبُ عليه

| الأثر | الإلزام |
| --- | --- |
| `F7-08` | الساقُ الثالثةُ مُسقَطةٌ — البندُ يستوفي `ح-4` (٣ جولاتٍ خضراءَ على `main` مُكتملةٌ منذ 2026-09-16) |
| `F7-05` | مُسقَطٌ — البندُ كلُّه عن النسخِ القارئةِ، والمالكُ قرَّرَ عدمَ بنائِها |
| `CAP-011` | مُغلَقٌ — الساقانِ المبنيّتانِ + الساقُ المسقطةُ = القدرةُ مُغلَقةٌ |
| الكتابةُ | تظلُّ تقرأُ الجداولَ الحارّةَ كلَّ ٦٠ ثانيةً — حملٌ ثابتٌ مقبولٌ |

## ٣) ما لا يُقرأُ من هذا القرارِ

- لا يُدَّعى أنَّ الحملَ على الجداولِ الحارّةِ صفرٌ
- لا يُدَّعى أنَّ التجميعَ المادِّيَّ يُغني عن النسخةِ في كلِّ حجمٍ — القرارُ للمُشهدِ الحاليِّ
- لا `مَقيس` ولا `مُثبَت` (`ح-5`)
