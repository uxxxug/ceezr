# واجهات النظام (API)

> **الحالة: هيكل فقط.** لا مسار منها منفّذ في الأمر الأول.

## مسارات Gateway (Hono) المخططة
| المسار | الطريقة | الغرض |
|---|---|---|
| `/health` | GET | فحص صحة للنشر |
| `/webhook/telegram/driver` | POST | تحديثات بوت السائق (تحقق من `TELEGRAM_WEBHOOK_SECRET`) |
| `/webhook/telegram/rider` | POST | تحديثات بوت الراكب |
| `/admin/api/*` | GET/POST | واجهة لوحة الإدارة الداخلية |

## دوال قاعدة البيانات الذرّية (RPC) المخططة
| الدالة | الغرض |
|---|---|
| `claim_ride` | أول قبول للمشوار يفوز، والباقي يُلغى |
| `claim_delivery` | نفس المنطق لطلبات التوصيل |
| `renew_subscription` | تجديد اشتراك ذرّي |
| `record_attendance` | تسجيل تبديل متاح/غير متاح |
| `register_unsubscribed_claim` | تسجيل أول ثلاث ضغطات في قروب غير المشتركين بالترتيب ومنع التكرار |
| `top_up_wallet` | شحن محفظة |
